# Security policy

## Supported versions

Security fixes are made for the latest released version of this integration.
If you use an older version, update before reporting a vulnerability.

## Reporting a vulnerability

Please report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/Nischay-Pro/ha-zebra/security/advisories/new).
Do not report security issues in a public issue. If private reporting is not
available, contact the maintainer through their GitHub profile before sharing
details publicly.

Include the affected integration version, Home Assistant version, and a clear
description of the impact. Remove printer addresses, serial numbers, passwords,
webhook IDs, and other private information from reports and logs.
